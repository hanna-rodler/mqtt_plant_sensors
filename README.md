# Plant Sensor Readings using MQTT

course: Pervasive Computing
Measuring and tracking plant data like the shining light, moisture, humidity and temperature.
In the frontend users can set how their plant is doing (healthy, moderate or critical). A python script then evaluates the plants. For unhealthy plants, it suggests solutions like that the temperature might be too high or the moisture too low in comparison to a healthy plant.

## Smart_Plants_esp32
Arduino setup and connection to the sensors.

## Backend
Express.js backend that is connected to MQTT

## Frontend
React.js frontend for displaying plant sensor data
